# ☕ Primeiro Projeto Java

Projeto desenvolvido durante meus estudos de Java na [Alura](https://www.alura.com.br/), com o objetivo de praticar os fundamentos da linguagem e fortalecer minha lógica de programação por meio de exercícios práticos.

Os exemplos utilizam o contexto do **Screen Match**, uma aplicação fictícia relacionada à avaliação de filmes, apresentada durante os estudos.

## 🎯 Objetivos de aprendizagem

- Compreender variáveis, tipos de dados e operadores.
- Trabalhar com entrada de dados utilizando `Scanner`.
- Aplicar estruturas condicionais e operadores lógicos.
- Utilizar laços de repetição para executar operações.
- Praticar cálculos, médias e manipulação de informações.
- Desenvolver o raciocínio lógico e a resolução de problemas.

## 🛠️ Tecnologias e ferramentas

- **Java** — linguagem de programação.
- **IntelliJ IDEA** — ambiente de desenvolvimento.
- **Git e GitHub** — versionamento e publicação do código.

## 📂 Estrutura do projeto

| Arquivo | Descrição |
|---|---|
| `Main.java` | Introdução ao Java, variáveis, cálculos e apresentação de informações sobre filmes. |
| `Leitura.java` | Leitura e exibição de dados informados pelo usuário. |
| `Condicional.java` | Prática de estruturas condicionais e operadores lógicos. |
| `Loop.java` | Utilização do `for` para coletar avaliações e calcular uma média. |
| `OutroLoop.java` | Utilização do `while` para receber avaliações até o encerramento da entrada. |

## 📚 Principais conceitos praticados

- Declaração e inicialização de variáveis.
- Tipos primitivos e conversão de tipos.
- Entrada e saída de dados.
- Estruturas `if` e `else`.
- Laços `for` e `while`.
- Operadores aritméticos, relacionais e lógicos.
- Acumulação de valores e cálculo de médias.
