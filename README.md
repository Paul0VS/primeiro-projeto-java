\# Primeiro Projeto Java



Projeto desenvolvido durante meus estudos de Java na Alura, com exercícios práticos para aprender os fundamentos da linguagem.



\## 📚 Conteúdos praticados



\- Variáveis e tipos de dados

\- Entrada de dados com `Scanner`

\- Estruturas condicionais (`if` e `else`)

\- Laços de repetição (`for` e `while`)

\- Operações matemáticas e cálculo de médias

\- Operadores lógicos e comparações

\- Fundamentos de lógica de programação



\## 🗂️ Arquivos do projeto



\- `Main.java`: primeiros conceitos de Java e apresentação do Screen Match.

\- `Leitura.java`: leitura de informações digitadas pelo usuário.

\- `Condicional.java`: exemplos de estruturas condicionais.

\- `Loop.java`: repetição com `for` e cálculo de média.

\- `OutroLoop.java`: repetição com `while` e avaliações.



\## 🛠️ Tecnologias



\- Java

\- IntelliJ IDEA

\- Git e GitHub



\## 🎯 Objetivo



Consolidar os fundamentos de Java por meio de exercícios práticos, desenvolvendo minha lógica de programação e construindo meu portfólio na área de desenvolvimento back-end.
